# Conxian Showcase dApp

An institutional-grade demonstration environment for the Conxian Protocol, showcasing hardware-enclosed signing, deterministic ERP synchronization, and automated settlement.

## 🚀 Features

- **Protocol Integration**: Direct connectivity to the Conxian Clarity 4 contract suite.
- **Sovereign Handshake**: Demonstrates non-custodial intent signing via the Conclave SDK.
- **Real-time Telemetry**: Integrated protocol health metrics from Conxian Nexus.
- **Earthy Corporate Finance**: Implements the standardized Conxian visual theme.

## 🏗️ Getting Started

First, run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Architecture

- **Frontend**: Next.js 15, React 19, Tailwind CSS.
- **Blockchain**: Stacks Layer 2 (Nakamoto Release).
- **Security**: Hardware-anchored identity via Conclave SDK.
