# Security Policy

For information on reporting vulnerabilities and the Conxian security posture, please refer to the [Root Security Policy](../SECURITY.md).

## Secrets and Environment Configuration

- Do not commit secret-bearing environment files (such as `.env`, `.env.local`, or `.env.production`).
- Environment templates (`.env.example`) may be committed for configuration guidance, but must contain safe placeholder values only.
- Refer to the [Root Security Policy](../SECURITY.md) for secret rotation guidelines and private vulnerability reporting protocols.
