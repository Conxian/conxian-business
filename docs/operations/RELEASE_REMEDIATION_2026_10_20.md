## Research decisions and primary references

- [GitHub artifact verification](https://cli.github.com/manual/gh_attestation_verify): verify signed artifact provenance with expected repository and trusted workflow identity; generating a provenance file or merely finding an artifact is insufficient. Use artifact digests and the verifier's structured success result, not a mutable name/latest pointer.
- [SLSA1.2 artifact verification](https://slsa.dev/spec/v1.2/verifying-artifacts): verify provenance authenticity, expected subject digest/builder/source and policy expectations. A valid signature alone is not an approval or proof of safe runtime behavior. No SLSA level is claimed by this work.
- [Render deploys](https://render.com/docs/deploys) and [health checks](https://render.com/docs/health-checks): observe deploy state and post-deploy behavior; qualify HTTP readiness separately from TCP listening. The Markdown references could not be parsed by the retrieval tool; the current HTML references were fetched instead.
- [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q): source-map-js versions below1.2.2 in the affected1.x range are vulnerable. Retain the already upgraded staged graph instead of suppressing dependency review or hand-editing an incomplete lockfile.
