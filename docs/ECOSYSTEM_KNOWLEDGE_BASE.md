### Coding Standards

| Language | Standard | Tool | Command |
|----------|----------|------|---------|

### Pre-commit Checklist

- [ ] Linear issue linked in PR
- [ ] All tests passing
- [ ] TypeScript types checked (`pnpm typecheck`)
- [ ] Rust clippy passing
- [ ] CHANGELOG updated (if user-facing)
- [ ] No secrets committed (gitleaks scan)
- [ ] Contamination guard passed (for `main`/`staged`)

```bash

# DON'T:
git submodule update --remote
git submodule foreach 'git checkout main'
```
