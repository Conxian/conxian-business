# Conxian Ecosystem Governance Advisory

This public-safe pointer summarizes where contributors should find versioned
technical, governance, and portfolio guidance. It intentionally excludes
internal strategy, operational status, staffing, financial planning, issue
triage, credentials, and other restricted material.

## Canonical public references

- [`AGENTS.md`](../AGENTS.md) — repository operating standards and security boundaries.
- [`docs/AGENTS.md`](AGENTS.md) — documentation, knowledge-retention, and hygiene rules.
- [`docs/BOS_KNOWLEDGE_FRAMEWORK.md`](BOS_KNOWLEDGE_FRAMEWORK.md) — public governance entities and relationships.
- [`docs/PORTFOLIO_BUSINESS_UNIT_MAP.md`](PORTFOLIO_BUSINESS_UNIT_MAP.md) — portfolio classifications and separation of concerns.
- [`docs/REPO_PORTFOLIO.md`](REPO_PORTFOLIO.md) — public repository roles and canonical links.
- [`CONTRIBUTING.md`](../CONTRIBUTING.md) — branch, pull-request, and review workflow.

## Change protocol

1. Keep sensitive strategy and operational material in the approved private
   knowledge systems; do not add it to Git.
2. Make changes on a feature or maintenance branch and open a pull request.
3. Promote approved changes through `dev -> staged -> main`; do not push
   directly to protected branches.
4. Record public-safe decisions and verification evidence in the canonical
   documents above.

For restricted planning or strategy requests, use the organization's approved
private knowledge workspace rather than extending this file.
