# cnx-consensus-engine: Exco Governance Manifest

## Function: Programmatic Decision-Making
Upgrades the legacy Exco meeting to a programmatic consensus engine. Operational shifts follow strict protocol logic.

## Programmatic Logic
1. **Proposal Lifecycle**: Drafting -> Time-Lock (144 blocks/24h) -> Multi-Sig Execution.
2. **Cryptographic Sign-off**: Requires threshold approval recorded in the State Layer.
3. **Automated Upgrade**: Once approved, the BOS automatically updates target parameters in Neon.

## MCP Wiring
- **Context7**: Storage of proposal context and history.
- **Neon**: Recording governance votes and outcomes.
